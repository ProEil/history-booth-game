歷史人物挑戰站｜正式插畫版

【上傳 GitHub Pages】
1. 解壓 ZIP。
2. 將 index.html、styles.css、app.js、images 資料夾內全部圖片，上傳至現有 GitHub repository 的根目錄。
3. 如果 GitHub 上已有同名檔案，請用新版覆蓋。
4. 保留 images 資料夾的名稱和檔案名稱；圖片不能只上傳 ZIP 而不解壓。
5. 等待 Pages 部署完成後，在 iPad Safari 開啟網址，必要時重新整理頁面。

【遊戲規則】
初級 P.1–P.3：10 題，6 題是非、4 題二選一；其中 5 題配有獨立歷史情境插畫。
進階 P.4–P.6：10 題三選一。
每位參加者抽一題、只可作答一次；答對派禮物，答錯給予解說與鼓勵。
點擊「下一位參加者」返回主頁，供下一位選擇年級。
題目在同一部裝置同一難度下以不重複循環抽取；不同 iPad 的抽題記錄互不相通。

【插畫】
images/warriors.webp：兵馬俑
images/journey.webp：張騫出使西域
images/court.webp：唐太宗與大臣議事
images/farm.webp：年少朱元璋的貧困生活
images/dictionary.webp：《康熙字典》
另有五位皇帝的彩色人物插畫。
插畫是教學用藝術示意圖，不是歷史文物照片或精確復原圖。

【活動前檢查】
在 iPad 上分別測試初級與進階，確認插畫載入、抽題、正誤提示及「下一位參加者」功能。

【圖片顯示規則（修正版）】
初級 P.1–P.3：只有 L01、L04、L05、L08、L10 五題顯示歷史情境插畫，其餘五題為純文字。
進階 P.4–P.6：十題全部純文字，不顯示題目圖片。首頁仍展示五位歷史人物插畫。
