歷史人物挑戰站｜精美插畫互動版

1. 將本資料夾的 index.html、app.js、styles.css 和 images/ 全部上傳至 GitHub Repository 根目錄。
2. GitHub Pages 選擇 main / (root)。
3. iPad Safari 開啟網址，建議橫向。
4. 首頁精美插畫上的兩個「開始挑戰」按鈕是真正可點擊的網頁按鈕。
5. 初級只有指定五題配情境圖片；進階十題完全不配題目圖片。
6. 每人一題，答後鎖定，按「下一位參加者」返回首頁。
7. 圖片中的文字為插畫的一部分；互動題目文字由網頁產生。
8. 請在正式活動前用 iPad 實際驗收。

本次更新：首頁取消「獎品介紹」，改為「認識五位歷史人物」，新增五位人物介紹頁。
